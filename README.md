
# 🎵 Spotify Music Recommendation System

A machine learning-based music recommendation system that uses **Spotify data and audio features** to recommend songs based on user preferences and similarity between tracks.

### 🚀 Features

* 🎧 Personalized song recommendations
* 🎵 Spotify API integration
* 📊 Audio-feature analysis of songs
* 🤖 Machine Learning-based similarity recommendations
* 🌐 Interactive Streamlit web application
* 📈 Data processing and visualization using Pandas, NumPy, and Matplotlib

### 🛠️ Technologies Used

**Python | Pandas | NumPy | Scikit-learn | Spotify API | Streamlit | Matplotlib**

### 💡 How It Works

The system processes Spotify song data and analyzes features such as **danceability, energy, valence, tempo, and acousticness**. It then identifies songs with similar characteristics and generates relevant recommendations for the user.

## Run locally

1. Create and activate a Python 3.10+ environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the Streamlit application:

   ```bash
   streamlit run app.py
   ```

The repository includes a small demo dataset in `data/spotify_data.csv` and a
`model.joblib` artifact generated by `md.ipynb`, so the recommender works offline.
The Spotify API pages are optional: copy `.env.example` to `.env` and set
`SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET` to enable live Spotify lookup.
Credentials are never stored in source control.

## Notebooks

Both `01.Eda.ipynb` and `md.ipynb` use the included dataset. Execute them from
the project root with:

```bash
jupyter nbconvert --to notebook --execute --inplace 01.Eda.ipynb
jupyter nbconvert --to notebook --execute --inplace md.ipynb
```
